- **Requirements:** PRD Phase 1 §7 (tokens only in memory, PKCE, no PII in URLs, i18n en/hi/mr, friendly errors, 170 KB budget, axe), §8 (UI scope), D1 (Keycloak sign-in, phone as username), D4 (one repository, pnpm monorepo); architecture `docs/architecture/06_FRONTEND.md`, ADR-009
- **Status:** Implemented
- **Owner:** growercare-frontend (new repository)
- **IDs:** rules FE-R1+, examples FE-E1+

## 1. Behaviour (rules)
| Rule | Given | When | Then |
|---|---|---|---|
| FE-R1 | not signed in | opening any route | redirected to Keycloak; after sign-in, back on the route opened (query string kept, nothing else) |
| FE-R2 | signed in | at any time | no token in localStorage, sessionStorage, IndexedDB or app cookies |
| FE-R3 | page reload with a live Keycloak session | start-up | signed in again without a login form (silent) |
| FE-R4 | access token about to expire | in use | refreshed in the background; if refresh fails, back to sign-in keeping the route |
| FE-R5 | an API answer | status | 401 → sign in again · 403 → "you can't do this" inline · 404 → the not-found page (same for missing and out of scope) · 409/412 → "changed by someone else", reload offered · 422 → the rule's message next to the form · 429 → "too many attempts, try again in N s" (Retry-After) · 503/504/network → friendly retry, the rest of the page keeps working |
| FE-R6 | any request | sent | carries `X-Request-Id` (UUID) and `Accept-Language`; a create carries an `Idempotency-Key` that is **reused** when the same submit is retried |
| FE-R7 | `/me` loaded | rendering | actions without the permission are not shown (`<Can>`) |
| FE-R8 | sign out | clicked | the query cache is cleared and the Keycloak session ended |
| FE-R9 | the language switcher | changed | every string switches; the choice survives a reload; no string is concatenated |
| FE-R10 | an ID from the API | anywhere | handled as a string (never `Number(id)`); no personal data in URLs (phone numbers go in bodies) |

## 2. Examples
| Example | Rule | Input | Expected |

## 3. Contracts used
`GET /api/iam/me` (both apps). Everything else per app (SPEC-FE-02, FE-03). Keycloak clients `grower-web` (redirects `http://localhost:5173/*`) and `staff-console` (`http://localhost:5174/*`) in local-platform's realm.

## 4. Data
No server data in Zustand or browser storage; browser storage holds only the language and UI preferences.

## 5. Security
| Concern | Rule |
|---|---|
| Tokens | memory only (R2); PKCE; public clients without secrets |
| XSS | no `dangerouslySetInnerHTML`; CSP in the nginx image (`default-src 'self'`, connect to the API and Keycloak only) |
| PII | masked as the API returns it; nothing personal in URLs or logs; no analytics in Phase 1 |

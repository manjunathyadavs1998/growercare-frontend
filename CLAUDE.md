# growercare-frontend: project guide for Claude

The GrowerCare web apps (PRD D4): `apps/grower-web` (growers, port 5173) and `apps/staff-console` (care, agronomists, territory managers, admins, retailers; port 5174), with shared packages. Every API call goes through the edge gateway (`/api/<service>/…`).

## Where things are
| Topic | Location |
|---|---|
| Specs | `docs/specs/frontend/` (01 foundation, 02 grower-web, 03 staff-console) |
| Architecture | growercare `docs/architecture/06_FRONTEND.md`, ADR-009; skill `.claude/skills/frontend-feature` (growercare) |
| API client | `packages/api-client`: contracts copied by `pnpm contracts:sync`, hooks generated by `pnpm api:generate` (orval, committed) |
| Shared packages | `auth` (oidc-client-ts, tokens in memory), `policy` (`<Can>`), `i18n` (FormatJS, en/hi/mr), `ui-kit`, `test-utils` |

## Conventions
1. **Server data only through the generated TanStack Query hooks**; Zustand only for UI state; no server data in browser storage.
2. **Tokens only in memory**; PKCE; one public Keycloak client per app (`grower-web`, `staff-console`).
3. **Every string through FormatJS**, in en, hi and mr (`pnpm i18n:check`); no concatenated sentences.
4. **IDs are strings**; no personal data in URLs (phone numbers go in request bodies).
5. **Errors by status** (SPEC-FE-01 R5): never a blank screen; 404 for missing and out of scope alike.
6. **Spec-driven:** spec rule → test named after the example id (`FE-E…`) → code. Tests: Vitest + Testing Library + MSW + axe.
7. **Reporting:** run `pnpm lint && pnpm typecheck && pnpm test:coverage && pnpm build` before claiming success.
8. **Git workflow:** never commit to `main`; branch `<type>/<name>`; PR body with `Spec: docs/specs/...`; squash-merge when CI, policy and review are green.
